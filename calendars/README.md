# 交易日历处理

V1.0.2不把“周一至周五”直接等同于交易日。

ChatGPT每日采集和周一补录时必须核对各市场官方交易日历、提前收盘、特殊交易和临时休市。区域文件是否预期存在，取决于该区域当日至少一个研究市场是否有应记录的交易或明确休市状态。

仓库中的`audit_missing_dates.py --weekdays-only`只生成候选缺失日期，不能作为最终补录依据。Codex必须在发起补录前再次核对官方日历。

如未来引入确定性交易日历库，应验证其对北京、上海、深圳、东京、孟买、伦敦、法兰克福和纽约的覆盖，包括印度特殊交易、日本午间休市、美国提前收盘及临时休市，再升级协议版本。
