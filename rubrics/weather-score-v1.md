# 天气评分规则 v1.0.0

天气评分是辅助解释指标，原始天气变量才是主要研究数据。每个窗口分别计算，不允许把全天数据替代开盘前或交易时段数据。

## 计算流程

1. 计算五个0—100分项。
2. 权重：体感温度25%、降水20%、天空与日照20%、空气质量20%、风与极端天气15%。
3. 缺失分项时，仅在至少3项可用且可用权重不少于60%时按可用权重重新归一化；否则评分不可用。
4. 内部指数0—100映射到1—10分：`ceil(index / 10)`，最低1分、最高10分。
5. 中等级预警将总指数封顶60，严重预警封顶40，极端预警封顶20。

## 分项函数

- 体感温度：18—24°C为100分；向寒冷或炎热方向按 `scripts/scoring.py` 中锚点分段线性下降。
- 降水：0 mm为100分；0.5、2、5、15、30、60 mm对应95、80、60、35、15、0分。
- 天空与日照：有云量时使用 `100 - 云量百分比`；有日照时长时使用窗口日照占比；两者均有则平均。
- AQI：0—50为100分；100、150、200、300对应70、40、15、0分。
- 风：阵风不超过20 km/h为100分；35、50、70、90 km/h对应80、55、25、0分。

## 禁止事项

- 不得凭文字印象自由打分。
- 不得将预测数据标记为观测数据。
- 不得用当前天气推测历史天气。
- 找不到数据时使用 `null` 和 `unavailable`，不得编造。
