# KOSPI Service Key availability

The official FSC Index Price Information OpenAPI requires a Public Data Portal
Service Key. This repository neither stores nor requests that key. The attempted
overseas individual registration path requires a Korean local mobile number and
does not offer an international-number or foreign-member alternative.

The registration attempt is closed. Do not use a virtual number, a borrowed
Korean number, or any other identity workaround. No account registration was
completed, no key was issued, no API request was made, no KOSPI data was
downloaded, and no cost was incurred.

This is a `credential_required` access blocker, not a paid-access, API-quality,
or licence-failure result. The prior setup instructions are intentionally
superseded pending a future source-selection decision.
